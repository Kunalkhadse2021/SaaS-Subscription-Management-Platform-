# SaaS Subscription Management Platform

## Project Overview
The SaaS Subscription Management Platform is a web-based application designed to manage software subscriptions efficiently. It helps administrators manage customers, subscription plans, billing information, renewals, and subscription statuses.

## Features
- User registration and login
- Customer management
- Create and manage subscription plans
- Subscribe to available plans
- Track subscription status
- Manage billing information
- Monitor subscription renewals
- Admin dashboard

## Technologies Used
- Frontend: React.js, HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT
